# TMAdminPlugins

Официальный репозиторий-реестр плагинов и манифестов обновлений для рабочего пространства системного администратора **TMAdmin**.

---

## Назначение репозитория
1. **Plugin Market Registry (`index.json`)**: Каталог доступных плагинов, версий, описаний, запрашиваемых прав и контрольных сумм.
2. **Хостинг архивов плагинов (`plugins/<id>/<version>/plugin.zip`)**: Хранение готовых архивов плагинов для прямой загрузки клиентом.
3. **Обновления десктопного приложения (`app/latest.json`)**: Манифест Tauri v2 Updater для автоматического обновления TMAdmin.

---

## Структура репозитория

```
TMAdminPlugins/
├── .github/
│   └── workflows/
│       └── validate.yml         # CI валидация index.json и проверка SHA-256
├── app/
│   └── latest.json              # Манифест обновления TMAdmin (Tauri Updater)
├── docs/
│   └── PUBLISHING.md            # Руководство по упаковке и публикации плагинов
├── plugins/
│   └── <plugin-id>/
│       └── <version>/
│           ├── plugin.zip       # Архив плагина
│           └── SHA256SUMS       # Хеш-сумма архива
├── index.json                   # Единый реестр маркета
└── README.md
```

---

## Как добавить или обновить плагин
Подробная пошаговая инструкция приведена в [docs/PUBLISHING.md](docs/PUBLISHING.md).
Кратко:
1. Создайте ветку от `main`.
2. Упакуйте плагин в `plugins/<id>/<version>/plugin.zip`.
3. Рассчитайте SHA-256 и запишите в `SHA256SUMS`.
4. Добавьте или обновите запись в `index.json`.
5. Откройте Pull Request — автоматический CI проверит корректность схемы и хешей.
